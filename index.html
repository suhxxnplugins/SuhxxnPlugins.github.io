Absolute Reality

The anti-cheat for WaffleSMP. It watches what each player's client sends and raises an alert when a move, aim or click cannot be real. It is a part of the server, not a separate product.

  • Alert-only
  • Java on Paper
  • PacketEvents
  • in development

Detection explorer

Pick a check. Where I have one, you see the real alert it raised in my test log.

Caught in a test runWritten and unit-tested, not tried live yet

How it decides

1. Read

It listens to the packets each client sends: movement, clicks, digging, placing and aim.

2. Judge

Each check compares those packets with what the game allows, and with the world that player can see.

3. Alert

If the evidence is strong, staff get one alert with the reason. Nobody is kicked or banned.

How it grew

  1. v0.10Packet-level core
    NoFall, Blink, Nuker, FastPlace, InvWalk, NoSlowdown.
  2. v0.11More hacked-client moves
    Criticals, MaceDMG, AntiHunger, FastLadder, Phase.
  3. v0.12Line of sight and floods
    WallHit, packet and inventory flood checks, bot-rhythm clicks.
  4. v0.13Aim and actions
    Steady-aim detection, sneak and sprint packet spam.
  5. v0.14Server-side timing
    FastBreak, NoWeb, Spinbot, Sneak, Elytra and vehicle checks.
  6. v0.15Water, sprint and ore
    LiquidSpeed, InvalidSprint and a first Xray statistic.

What it does not catch yet

  • Subtle aim assist and trigger bots. A first version missed Wurst's AimAssist.
  • Nuker in survival mode, which looks like a very fast honest digger.
  • Anything that only changes what the cheater sees, such as ESP or Xray textures. WaffleSMP uses Paper's anti-xray for that.

It does not punish anyone. I want weeks of real play without false alarms first.

How a project goes

  1. Request
    You send the request form. I reply with questions and a quote.
  2. Scope in writing
    What it does, what it does not do, your Minecraft version, the date.
  3. Build and test
    I run it on a live Paper server and send you logs, not just a build.
  4. Handover
    Jar and source, build files and a short notes file with the version and known limits.

Questions

Which Minecraft versions do you support?

Paper, on the version you run. Tell me the exact version in the request. Plugins can break when Minecraft updates, so I note the supported version in the handover.

Do I get the source code?

Yes, source and build files are included. Who owns the code and whether I may reuse generic parts is agreed up front.

What do you not build?

Cheats, anything that harms other players or servers, and anything I cannot test reliably. I will say so before you pay for it.

How much does it cost?

It depends on the size of the plugin. Send a request and I will quote a fixed price for the agreed scope.

Do you use AI tools?

Yes, as part of how I work. I test everything on a real server and I am the one who answers for the result.

Ready to start?

A short request is enough. I will ask if I need more.
