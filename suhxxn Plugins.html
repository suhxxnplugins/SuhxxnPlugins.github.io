Selected work

Absolute Reality

An alert-only anti-cheat for Paper servers, written in Java on PacketEvents. It reads what a client sends and says when the movement, aiming or clicking could not come from a real player.

  • Java
  • Paper 26.x
  • PacketEvents
  • In development, v0.12

I test it against a hacked client on my own server, then fix what it misses or gets wrong. The detection rules are plain Java with unit tests, so each one can be checked without starting a server.

What it does not catch yet

  • Subtle aim assist and trigger bots.
  • Nuker in survival mode, which looks like a very fast honest digger.
  • Vehicle and Elytra hacks.
  • Anything that only changes what the cheater sees, such as ESP or Xray. That needs server-side world hiding, not detection.

It only sends alerts. It never kicks or bans, because I have not yet run it long enough on real players to trust it with punishments.
